# 🎓 SAMSTRACK - Student Attendance Management System

SAMSTRACK is a full-stack web application designed to simplify student attendance management for educational institutions. It enables administrators and faculty members to manage students, courses, and attendance records through an intuitive interface while providing accurate attendance tracking and reporting.

---

## 📌 Project Overview

The system eliminates manual attendance registers by providing a digital platform where faculty can mark attendance, manage student information, and generate attendance reports efficiently.

---

## 🚀 Features

- User Authentication & Login
- Student Registration and Management
- Faculty Management
- Course Management
- Attendance Marking
- View Daily Attendance Records
- Attendance Reports
- Search and Filter Students
- Responsive User Interface
- RESTful API Integration

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/SAMSTRACK.git
```

### Backend

```bash
cd backend
```

Configure MySQL database in

```
application.properties
```

Run

```bash
mvn spring-boot:run
```

### Frontend

```bash
cd frontend
npm install
npm start
```

Application will start at

```
http://localhost:3000
```

Backend runs on

```
http://localhost:8091

## 📡 REST APIs

Some of the APIs used in the project:

| Method | Endpoint | Description |
|---------|----------|-------------|
| POST | /login | User Login |
| GET | /students | Get All Students |
| POST | /students | Add Student |
| PUT | /students/{id} | Update Student |
| DELETE | /students/{id} | Delete Student |
| POST | /attendance | Mark Attendance |
| GET | /attendance | View Attendance |
